How I work

Question, data, check, finding

Four stages for any dataset, shown here on the charging register.

  1. 1 Question

    Pin down what is being counted before comparing anything.

  2. 2 Data

    Put sources on a fair footing: rates instead of raw size, dates kept apart.

  3. 3 Check

    Apply one rule to everything and watch what moves. Unmatched rows stay visible.

  4. 4 Finding

    Write only what survives, with its status and limits.

Python and SQL pipelines with pytest checks; results in a Power BI report and a written analysis.
